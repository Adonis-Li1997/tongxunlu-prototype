## 设计风格

- **风格定位**：简洁高级 + 块状填充图标
- **主色**：`#1C6CF5`（沉稳蓝）
- **圆角**：16px / 24px 大圆角
- **留白**：宽松间距（md: 20px, xl: 48px）
- **图标**：统一块状填充风格，与大圆角视觉统一
- **明暗双模式**：亮色 + 暗色完整支持

## 如何使用

**查看原型**：用浏览器打开 `04-原型/prototype.html`
- 左侧栏可切换页面、切换暗色模式、收起侧栏
- 手机框内可点击交互，所有按钮都有真实跳转
- 右下角「+」是新增联系人的浮动按钮

**查看 PRD**：用浏览器打开 `05-PRD/PRD.html`
- 左侧目录可跳转，滚动时自动高亮当前章节
- 支持暗色模式切换，可直接打印导出 PDF
