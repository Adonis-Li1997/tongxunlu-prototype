# 设计规范

## 风格来源

**自定义风格：简洁高级 + 块状填充图标**

**风格关键词 → token 映射：**

| 关键词 | 映射到 token | 调整说明 |
|---|---|---|
| 简洁 | `--shadow-md` 极淡 `rgba(26,29,34,.06)` | 去掉浓重投影，靠留白和细边框分隔层级 |
| 高级 | 主色降饱和 `#1C6CF5`，字重偏轻 | 不用高饱和艳蓝，用沉稳偏灰的蓝色 |
| 大留白 | `spacing-md: 20px`、`spacing-xl: 48px` | 比 Apple 风再大一圈，呼吸感更强 |
| 微圆角 | `radius-md: 10px`、`radius-lg: 14px` | 中等微圆，克制精致不生硬 |
| 块状图标 | `icon.style: filled` | 统一填充风格，不使用线描图标 |

## 风格说明

整体走「克制、通透、沉稳」的路线——浅灰底上漂浮白色卡片，主色只用在关键操作和图标上，大量留白让信息自己呼吸。图标全部使用块状填充风格（SF Symbols filled），与大圆角卡片形成视觉统一。明暗两套完整支持，暗色下卡片为深灰蓝调、底色纯黑。

## Token 总览

### 颜色

| 变量 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--color-primary` | `#1C6CF5` | `#4F8BFF` | 主按钮、块状图标、选中态、头像底色 |
| `--color-onPrimary` | `#FFFFFF` | `#FFFFFF` | 主色块上的文字与图标 |
| `--color-background` | `#F6F7F9` | `#000000` | 页面底色（分组列表间隔色） |
| `--color-surface` | `#FFFFFF` | `#1A1C20` | 卡片、列表单元格、输入框底色 |
| `--color-textPrimary` | `#1A1D22` | `#F1F2F4` | 姓名、标题、主文字 |
| `--color-textSecondary` | `#7E8592` | `#9DA3AE` | 电话号码、公司、备注、时间戳 |
| `--color-border` | `#E6E8EC` | `#2C2F36` | 分割线、边框（极淡，若有若无） |

### 圆角

| 变量 | 值 | 用途 |
|---|---|---|
| `--radius-sm` | `6px` | 小按钮、标签、小图标背景 |
| `--radius-md` | `10px` | 列表组卡片、输入框、弹窗内容 |
| `--radius-lg` | `14px` | 大按钮、底部面板、大头像 |
| `--radius-full` | `999px` | 胶囊按钮、圆形头像、FAB |

### 间距

| 变量 | 值 | 用途 |
|---|---|---|
| `--spacing-xs` | `4px` | 图标与文字间距、标签内边距 |
| `--spacing-sm` | `8px` | 列表项内垂直小间距 |
| `--spacing-md` | `20px` | 页面左右边距、卡片内边距 |
| `--spacing-lg` | `28px` | 模块间距、大标题下间距 |
| `--spacing-xl` | `48px` | 页面顶部大留白、空状态上下间距 |

### 字体

| 变量 | 值 | 用途 |
|---|---|---|
| `--font-family` | `-apple-system, 'SF Pro Display', 'SF Pro SC', 'PingFang SC', sans-serif` | 全局字体栈（优先 SF Pro） |
| `--font-size-xs` | `11px` | 辅助标签、时间戳、角标 |
| `--font-size-sm` | `13px` | 次级文字、电话号码、公司名 |
| `--font-size-base` | `16px` | 正文、列表项主文字 |
| `--font-size-lg` | `19px` | 详情页姓名、分组标题 |
| `--font-size-xl` | `26px` | 页面大标题（导航栏大标题模式） |
| `--font-size-2xl` | `34px` | 欢迎页 / 空状态主标题 |

### 阴影

| 变量 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--shadow-md` | `0 2px 12px rgba(26,29,34,.06)` | `0 4px 24px rgba(0,0,0,.5)` | 浮动按钮、底部面板（极淡，几乎不可见） |

### 图标规范

- **风格**：统一块状填充（filled），不使用线描（outlined）风格
- **来源**：SF Symbols filled 变体 或 自定义同风格图标
- **圆角**：图标内部圆角与整体微圆角风格一致，不用尖锐直角或过度大圆
- **粗细**：线条粗细均匀，视觉重量一致
- **尺寸**：导航栏图标 22pt、列表图标 24pt、大图标 32pt
- **颜色**：激活态用主色 `--color-primary`，普通态用主文字色 `--color-textPrimary`，禁用态用次文字色 `--color-textSecondary`

## 组件用法要点

本项目为 iOS 移动端通讯录，使用 `components-mobile.md` 组件库，做以下定制：

**关键组件与用法：**

- **导航栏**：大标题模式 + 透明背景 + 滚动时模糊毛玻璃效果
- **列表分组**：联系人按拼音首字母分组，iOS 风格分组列表 + 右侧索引条
- **联系人卡片**：圆形头像 + 姓名（semibold）+ 公司/号码（次级），左对齐
- **块状图标**：所有操作入口（设置、分享、拨号、短信）全部使用填充风格图标
- **FAB**：右下角悬浮「+」按钮，圆形，主色填充，白色 + 号图标
- **表单**：新增/编辑页用分组卡片式表单，表单项左图标右文字
- **底部面板**：分享面板、删除确认从底部上滑，大圆角顶部
- **搜索框**：首页顶部搜索栏，圆角胶囊形，放大镜图标在左
- **空状态**：居中大图标（块状填充）+ 大标题 + 说明 + 主操作按钮
