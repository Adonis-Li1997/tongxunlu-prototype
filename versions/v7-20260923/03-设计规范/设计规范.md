# 设计规范

## 风格来源

**自定义风格：简洁高级 + 块状填充图标**

**风格关键词 → token 映射：**

| 关键词 | 映射到 token | 调整说明 |
|---|---|---|
| 简洁 | `--shadow-md` 极淡 `rgba(26,29,34,.06)` | 去掉浓重投影，靠留白和细边框分隔层级 |
| 高级 | 主色降饱和 `#1C6CF5`，字重偏轻 | 不用高饱和艳蓝，用沉稳偏灰的蓝色 |
| 大留白 | `spacing-md: 20px`、`spacing-xl: 48px` | 比 Apple 风再大一圈，呼吸感更强 |
| 微圆角 | `radius-md: 10px`、`radius-lg: 14px` | 中等微圆，克制精致不生硬 |
| 块状图标 | `icon.style: filled` | 统一填充风格，不使用线描图标 |

## 风格说明

整体走「克制、通透、沉稳」的路线——浅灰底上漂浮白色卡片，主色只用在关键操作和图标上，大量留白让信息自己呼吸。图标全部使用块状填充风格（SF Symbols filled），与大圆角卡片形成视觉统一。明暗两套完整支持，暗色下卡片为深灰蓝调、底色纯黑。

### 阴影

| 变量 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--shadow-md` | `0 2px 12px rgba(26,29,34,.06)` | `0 4px 24px rgba(0,0,0,.5)` | 浮动按钮、底部面板（极淡，几乎不可见） |

### 图标规范

- **风格**：统一块状填充（filled），不使用线描（outlined）风格
- **来源**：SF Symbols filled 变体 或 自定义同风格图标
- **圆角**：图标内部圆角与整体微圆角风格一致，不用尖锐直角或过度大圆
- **粗细**：线条粗细均匀，视觉重量一致
- **尺寸**：导航栏图标 22pt、列表图标 24pt、大图标 32pt
- **颜色**：激活态用主色 `--color-primary`，普通态用主文字色 `--color-textPrimary`，禁用态用次文字色 `--color-textSecondary`

## 组件用法要点

本项目为 iOS 移动端通讯录，使用 `components-mobile.md` 组件库，做以下定制：

**关键组件与用法：**

- **导航栏**：大标题模式 + 透明背景 + 滚动时模糊毛玻璃效果
- **列表分组**：联系人按拼音首字母分组，iOS 风格分组列表 + 右侧索引条
- **联系人卡片**：圆形头像 + 姓名（semibold）+ 公司/号码（次级），左对齐
- **块状图标**：所有操作入口（设置、分享、拨号、短信）全部使用填充风格图标
- **FAB**：右下角悬浮「+」按钮，圆形，主色填充，白色 + 号图标
- **表单**：新增/编辑页用分组卡片式表单，表单项左图标右文字
- **底部面板**：分享面板、删除确认、号码选择等从底部上滑，大圆角顶部
- **搜索框**：首页顶部搜索栏，圆角胶囊形，放大镜图标在左
- **空状态**：居中大图标（块状填充）+ 大标题 + 说明 + 主操作按钮
- **Toast 提示**：操作反馈轻提示，居中半透明黑底，竖排图标+文字

## 组件详细规范

### 底部面板（Action Sheet / Share Sheet / Confirm Sheet）

**适用场景**：多选项操作面板、分享面板、删除/确认等二次确认弹窗

**结构规范**：
- **触发方式**：从底部向上滑入，带 `sheetUp` 动画（0.25s ease-out）
- **蒙层**：`rgba(0,0,0,0.4)` 半透明黑色全屏蒙层，点击蒙层关闭
- **面板**：顶部大圆角 `16px 16px 0 0`，背景色 `--color-surface`
- **底部安全区**：底部预留 `env(safe-area-inset-bottom)` 适配刘海屏
- **滚动锁定**：面板打开时，页面内容禁止滚动（`overflow: hidden`）

**变体类型**：

| 类型 | 说明 | 示例 |
|---|---|---|
| 操作列表型 | 标题 + 多个列表项 + 取消按钮 | 号码选择器 |
| 分享网格型 | 顶部把手 + 标题 + 横向图标网格 + 取消按钮 | 分享面板 |
| 确认提示型 | 图标 + 标题 + 描述 + 主按钮 + 次按钮 | 删除确认弹窗 |

**按钮规范**：
- 主操作按钮：`--color-primary` 填充 + 白色文字，胶囊圆角 `--radius-full`，高度 48px
- 次要/取消按钮：`--color-surface` 背景 + `--color-border` 边框 + `--color-textPrimary` 文字，胶囊圆角，高度 48px
- 危险操作按钮：`--color-danger` 填充 + 白色文字（仅用于不可逆操作确认）

**交互规范**：
- 页面切换时自动关闭所有打开的底部面板
- 面板内跳转页面时先关闭面板再跳转
- 点击蒙层或取消按钮关闭面板

### Toast 轻提示

**适用场景**：操作成功/失败的短时反馈（如复制成功、保存成功等）

**视觉规范**：
- **位置**：屏幕正中央
- **背景**：`rgba(0,0,0,0.75)` 半透明黑色
- **圆角**：12px
- **内边距**：18px 24px
- **最小宽度**：140px
- **文字**：白色，15px，居中
- **图标**：`✓` 对勾符号，28px，白色，位于文字正上方
- **布局**：竖排居中（图标在上，文字在下），间距 10px
- **动画**：缩放淡入 `toastFade`（0.2s ease-out，从 0.9 倍透明度 0 到 1 倍透明度 1）

**交互规范**：
- 显示时长：默认 1.5 秒后自动消失
- 不阻塞用户操作（`pointer-events: none`）
- 页面切换时自动关闭
- 同一时间只显示一个 Toast，重复触发重置计时器
