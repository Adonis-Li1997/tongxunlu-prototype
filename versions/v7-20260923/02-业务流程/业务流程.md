# 业务流程

## 主流程一：联系人浏览与查找

```mermaid
flowchart TD
  onboarding[首次使用引导] -->|完成引导| home[联系人首页]
  home -->|点击搜索框| search[搜索结果]
  home -->|点击联系人| contact-detail[联系人详情]
  search -->|点击搜索结果| contact-detail
  home -->|点击设置图标| settings[设置]
  contact-detail -->|返回| home
  search -->|返回| home
  settings -->|返回| home
```

## 主流程二：新增与导入联系人

```mermaid
flowchart TD
  home -->|点击右上角+| contact-add[新增联系人]
  contact-add -->|保存| contact-detail
  settings -->|导入联系人| import[导入方式选择]
  empty-state[空状态] -->|导入联系人| import
  onboarding[首次使用引导] -->|立即导入| import
  import -->|系统通讯录| import-system[系统通讯录导入]
  import -->|粘贴识别| import-paste[粘贴识别]
  import -->|名片OCR| import-ocr[名片OCR]
  import -->|手动新增| contact-add
  import-system -->|导入完成| home
  import-paste -->|识别并保存| contact-add
  import-ocr -->|识别并编辑| contact-add
```

## 主流程三：智能排重与合并

```mermaid
flowchart TD
  settings[设置] -->|联系人去重| duplicate-scan[重复联系人扫描]
  duplicate-scan -->|点击一组重复项| duplicate-merge[重复合并详情]
  duplicate-merge -->|确认合并| contact-detail[联系人详情]
  duplicate-merge -->|返回| duplicate-scan
  duplicate-scan -->|返回| settings
```

## 主流程四：联系人编辑与删除

```mermaid
flowchart TD
  contact-detail[联系人详情] -->|点击编辑| contact-edit[编辑联系人]
  contact-edit -->|保存| contact-detail
  contact-detail -->|删除联系人| home[联系人首页]
```

## 主流程五：拨号与发短信

```mermaid
flowchart TD
  contact-detail[联系人详情] -->|点击拨号| dial-pad[拨号盘]
  contact-detail[联系人详情] -->|点击短信| sms-compose[发短信]
  dial-pad -->|返回| contact-detail
  sms-compose -->|返回| contact-detail
```

## 主流程六：名片分享与 Deep Link

```mermaid
flowchart TD
  contact-detail[联系人详情] -->|点击分享| share-sheet[分享面板]
  share-sheet -->|分享到微信| h5-card[H5名片页]
  h5-card -->|已安装App Deep Link| contact-detail
  h5-card -->|未安装 下载引导| h5-card
```
